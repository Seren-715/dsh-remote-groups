# DSH 多 Agent 群聊

本社区衍生版本由 Seren-715 修改，基于 Fei2411/DeepSeek-Bot，按 Apache-2.0 发布。

DSH、Codex CLI、Claude Code、OpenCode 与 Hermes 可以加入群聊，按 @提及或有发言次数上限的讨论协作。CLI 使用各自现有登录和模型，工作发生在群聊专用会话，不接管已有桌面窗口。

整合安装、手机端功能和当前限制以仓库根目录的 [README](../README.md) 为准。设计见 [local-agent-group-chat](docs/plans/2026-10-19-local-agent-group-chat.md)。本机开发/登录状态不代表其他电脑已经连通。
